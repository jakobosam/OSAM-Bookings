OSAM release keys

Generates everything the signed-update setup needs, entirely in this browser (nothing is sent anywhere). Open this file from your computer, click Generate, and copy each value to where it says. Close the tab when you're done — the private key isn't saved.

OSAM_SIGNING_KEY — private key (keep secret)

GitHub → OSAM-Bookings → Settings → Environments → release-signing → Add environment secret. Put it nowhere else.

OSAM_PUBLIC_KEY — public key

GitHub → Settings → Secrets and variables → Actions → Variables tab → New repository variable. Also the PUBLIC_KEY environment variable of the Node.js app in cPanel.

ADMIN_TOKEN

cPanel Node.js app environment variable ADMIN_TOKEN, and GitHub repository secret UPDATE_SERVER_ADMIN_TOKEN.

WEBHOOK_SECRET (optional)

cPanel Node.js app environment variable WEBHOOK_SECRET, and the Secret of a GitHub webhook (Settings → Webhooks) to https://updates.osamweb.com/v1/webhook/github for “Releases” events.
